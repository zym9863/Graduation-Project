# 方法设计

## 研究目标

题目为《基于新闻价值理论的多模态特征提取及其在个性化新闻推荐中的应用》。工程目标是验证在个性化新闻推荐中逐步引入视觉信息和新闻价值信息后，推荐效果是否提升。

实验分为三组：

1. Text：仅使用新闻文本特征。
2. Text+Image：使用新闻文本和图片特征。
3. Text+Image+Value：在图文特征基础上加入新闻价值特征。

目标趋势为 `Text < Text+Image < Text+Image+Value`。如果最终真实实验结果未完全符合该趋势，论文应保留真实结果并从标注覆盖率、价值维度噪声、样本规模和模型容量等角度分析。

## 数据

MIND-small 提供新闻文本、用户历史点击和候选新闻曝光记录。`newData/` 提供以新闻 ID 命名的图片文件。工程中将 `news.tsv` 的 `news_id` 与 `newData/{news_id}.jpg` 对齐。

## 特征

图文编码器使用 SigLIP `google/siglip-base-patch16-224`。

文本输入由 `category + subcategory + title + abstract` 拼接而成。图像输入为新闻对应图片。为了降低训练成本，SigLIP 特征预计算并缓存，推荐模型训练阶段只读取向量。

## 新闻价值标注

新闻价值维度包括重要性、显著性、冲突性、新奇性、人情味，每个维度为 `0-3` 分。工程不使用时效性和接近性，因为数据缺少可靠发布时间、地理位置和用户位置。

LLM 标注按高频新闻优先抽样，结果写入 JSONL 缓存。未标注新闻在价值模态中使用零向量，并额外加入 missing mask，避免把缺失误解释为低价值。

为验证自动标注可信性，工程增加双模型交叉标注一致性检验：保留 `qwen3.5-flash` 生成的主标签作为推荐模型输入，再按主标签总分分层抽取 300 条新闻，用 `qwen3.5-plus` 在相同 prompt 和评分规则下独立复核。复核结果不替换训练标签，只用于计算精确一致率、`|差值|≤1` 一致率、MAE、相关系数和二次加权 Cohen's Kappa，并生成总分散点图、五维混淆矩阵和分歧样例表。

## 推荐模型

推荐模型使用统一的用户历史池化结构。候选新闻和历史新闻先经过同一个 MLP 编码器，再对历史新闻向量进行 masked mean pooling 得到用户向量，最后用用户向量与候选新闻向量点积打分。

三组模型仅改变候选和历史新闻的输入特征，训练样本、验证样本和评价指标保持一致。
